# Explora Animalia — Unidad didáctica para grado noveno

Sitio web educativo e interactivo sobre la clasificación del reino Animalia, diseñado como recurso de apoyo para Ciencias Naturales y Biología de grado noveno.

## Contenido del proyecto

- `index.html`: estructura y contenido pedagógico.
- `styles.css`: diseño visual adaptable a computadores y celulares.
- `script.js`: menú móvil, reto interactivo de clasificación y evaluación automática.

## Cómo visualizar el sitio en tu computador

1. Descarga y descomprime la carpeta del proyecto.
2. Abre la carpeta `UNIDAD-DIDACTICA-ANIMALES`.
3. Haz doble clic en `index.html`.
4. Se abrirá en tu navegador. Para que se vea correctamente, conserva los tres archivos en la misma carpeta.

No necesitas instalar programas para abrir la página.

## Cómo subirlo a GitHub desde el navegador

1. Inicia sesión en [GitHub](https://github.com/).
2. Abre tu repositorio `UNIDAD-DIDACTICA-`.
3. Selecciona **Add file** y luego **Upload files**.
4. Arrastra los archivos `index.html`, `styles.css`, `script.js` y `README.md` (o los archivos extraídos de esta carpeta) al área de carga.
5. En el campo de confirmación escribe: `Añadir unidad didáctica de clasificación animal`.
6. Selecciona **Commit changes**.

## Cómo publicar el sitio con GitHub Pages

1. Dentro del repositorio, entra en **Settings**.
2. En el menú lateral selecciona **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Pulsa **Save**.
6. Espera a que GitHub Pages publique el sitio. La dirección aparecerá en esa misma sección.

## Propósito de aprendizaje

Comprender los principios de clasificación biológica del reino Animalia mediante el reconocimiento de características morfológicas, fisiológicas y evolutivas; diferenciar grupos de animales e interpretar relaciones de parentesco.

## Nota académica

Este recurso es una propuesta didáctica inicial. Antes de presentarlo como producto final, conviene ajustar la duración, los desempeños, los criterios de evaluación y las referencias a los lineamientos curriculares y al plan de área de la institución educativa.
